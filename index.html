⚡Politique de Confidentialité

MojiShock - Jeu Mobile
Dernière mise à jour : 14 avril 2026
En bref : MojiShock est un jeu gratuit qui respecte votre vie privée. Nous collectons des données d'utilisation anonymes pour améliorer le jeu. Nous utilisons une authentification anonyme pour le classement en ligne. Aucune donnée personnelle identifiable n'est requise. Le jeu utilise des publicités pour rester gratuit, et propose des achats intégrés optionnels (suppression des publicités, skins cosmétiques) traités directement par Google Play et l'App Store.

2. Analyse d'utilisation (Analytics) NOUVEAU

MojiShock utilise Firebase Analytics (Google) pour collecter des données anonymes sur l'utilisation de l'application. Ces données nous aident à améliorer l'expérience de jeu.

MojiShock utilise Firebase Analytics (Google) pour collecter des données anonymes sur l'utilisation de l'application. Ces données nous aident à améliorer l'expérience de jeu.

Données collectées automatiquement :

  • Données de session : fréquence d'ouverture de l'app, durée des sessions, nombre de parties jouées
  • Données de gameplay : scores atteints, niveaux complétés, modes de jeu utilisés, progression dans l'aventure
  • Données de performance : obstacles franchis, combos réalisés, causes de fin de partie
  • Données techniques : type d'appareil, version du système d'exploitation, version de l'app
  • Données publicitaires : interactions avec les publicités (visionnage, skip)

Finalités de cette collecte :

  • Améliorer l'équilibrage et la difficulté du jeu
  • Identifier les points de friction et bugs
  • Comprendre quelles fonctionnalités sont les plus appréciées
  • Optimiser l'expérience publicitaire
⚠️ Important : Ces données sont anonymes et ne permettent pas de vous identifier personnellement. Elles sont associées à un identifiant technique aléatoire, pas à votre identité.

Conservation des données analytics :

Les données analytics sont conservées pendant 14 mois maximum, conformément aux paramètres par défaut de Firebase Analytics.

3. Classement en ligne (Leaderboard)

MojiShock propose un classement mondial optionnel utilisant Firebase :

MojiShock propose un classement mondial optionnel utilisant Firebase :

  • Authentification anonyme : Un identifiant unique anonyme est généré automatiquement pour votre appareil. Aucun email ni mot de passe n'est requis.
  • Pseudo choisi : Vous choisissez un pseudo (2-15 caractères) pour apparaître dans le classement. Ce pseudo ne doit pas contenir d'informations personnelles.
  • Données du classement : Seuls votre pseudo, meilleur score et meilleur combo sont stockés sur nos serveurs Firebase.
  • Participation optionnelle : Vous pouvez choisir de ne pas soumettre vos scores au classement.

Les données du classement sont hébergées sur Google Firebase (Firestore). Pour plus d'informations, consultez la Politique de confidentialité de Firebase.

6. Achats intégrés (In-App Purchases) NOUVEAU

MojiShock propose des achats intégrés optionnels pour améliorer l'expérience de jeu. Tous les achats sont traités directement par Google Play Billing (Android) ou Apple StoreKit (iOS) — nous ne voyons et ne stockons jamais vos informations de paiement.

Produits disponibles :

  • Suppression des publicités — supprime les publicités interstitielles (les publicités rewarded optionnelles restent disponibles pour obtenir des récompenses)
  • Skins cosmétiques premium — apparences exclusives pour votre personnage, sans aucun impact sur le gameplay
  • Pack de démarrage (Starter Pack) — ensemble ponctuel de pièces et de consommables pour accélérer votre progression
Pas de pay-to-win : aucun achat n'octroie d'avantage compétitif permanent. Les compagnons, relics et compétences restent débloquables uniquement via le gameplay. Les achats intégrés sont exclusivement cosmétiques ou pratiques (suppression des publicités).

Données collectées lors d'un achat :

  • Identifiant de produit acheté (ex : remove_ads) — stocké localement sur votre appareil pour appliquer l'avantage correspondant
  • Reçu d'achat (receipt) — signature cryptographique fournie par le store, conservée localement pour vérifier la validité et permettre la restauration
  • Aucune donnée bancaire — ni nom, ni adresse, ni numéro de carte. Tout est géré par Google Play / App Store.

Restauration des achats :

Un bouton « Restaurer mes achats » est disponible dans les paramètres de l'application. Il permet de récupérer vos achats non-consommables (suppression des publicités, skins) si vous changez d'appareil ou réinstallez l'application, via votre compte Google / Apple habituel.

Remboursements :

Pour demander un remboursement, contactez directement Google Play (instructions) ou Apple (instructions). Nous n'avons pas accès aux transactions financières et ne pouvons donc pas traiter de remboursement directement.

Protection des mineurs :

Nous recommandons aux parents de configurer les contrôles parentaux via Google Family Link (Android) ou Screen Time (iOS) pour empêcher les achats non autorisés. Les achats intégrés nécessitent une confirmation explicite par le système d'exploitation à chaque transaction.

8. Stockage des données

Données locales : Vos paramètres, progression et statistiques sont stockés localement sur votre appareil via SharedPreferences. Ces données :

  • Ne sont jamais transmises à nos serveurs (sauf les scores pour le classement)
  • Peuvent être supprimées en désinstallant l'application

Données en ligne : Si vous participez au classement ou utilisez l'app normalement, vos données sont stockées sur Firebase :

  • Hébergés dans l'Union Européenne (europe-west1)
  • Associés uniquement à un identifiant anonyme
  • Données analytics : conservées 14 mois maximum
  • Données classement : conservées tant que le classement est actif

9. Permissions de l'application

MojiShock demande les permissions suivantes :

  • Internet : Nécessaire pour les publicités, le classement en ligne et les analytics
  • Vibration : Pour le retour haptique lors du jeu (optionnel, peut être désactivé)
  • Facturation (com.android.vending.BILLING, Android uniquement) : Permet les achats intégrés via Google Play. N'autorise aucun prélèvement automatique — chaque achat demande une confirmation explicite.

10. Protection des enfants

MojiShock est un jeu familial adapté à tous les âges. Nous ne collectons pas sciemment d'informations personnelles auprès d'enfants de moins de 13 ans. Le classement utilise uniquement des pseudos choisis par l'utilisateur.

Les publicités affichées sont conformes aux politiques de Google concernant le contenu adapté aux familles.

11. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : Demander quelles données sont collectées vous concernant
  • Droit de rectification : Modifier vos données (pseudo du classement)
  • Droit à l'effacement : Demander la suppression de vos données
  • Droit d'opposition : Refuser la collecte de certaines données
  • Droit à la portabilité : Obtenir vos données dans un format lisible

Comment exercer vos droits :

  • Réinitialiser votre identifiant publicitaire dans les paramètres de votre appareil
  • Activer "Limiter le suivi publicitaire" dans les paramètres de votre appareil
  • Choisir de ne pas participer au classement en ligne
  • Nous contacter pour demander la suppression de vos données de classement
  • Supprimer toutes les données locales en désinstallant l'application
Désactiver les analytics : Vous pouvez limiter la collecte de données analytics en activant l'option "Limiter le suivi publicitaire" (iOS) ou "Désactiver la personnalisation des annonces" (Android) dans les paramètres de votre appareil.
